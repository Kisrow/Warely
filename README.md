# Warely

Warely — pet-проект для управления складскими запасами.

## Функционал

На текущий момент реализовано:

- Авторизация через Supabase
- Навигация
- Главный layout приложения
- Боковое меню навигации
- Загрузка списка товаров из Supabase
- Отображение товаров в таблице Ant Design
- Клиентская пагинация

## Технологии

### Frontend

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- React Hook Form
- Zod
- Ant Design

### Backend / Infrastructure

- Supabase
- PostgreSQL

## Архитектура

Проект построен с использованием Feature-Sliced Design (FSD).

Структура приложения разделена на:

- `pages` — страницы приложения
- `widgets` — крупные UI-блоки
- `features` — пользовательские сценарии
- `entities` — бизнес-сущности
- `shared` — переиспользуемая инфраструктура и утилиты

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```
